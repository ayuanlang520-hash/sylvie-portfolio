阅迹 · 项目过程与当前进度 ＋

为什么做

我的阅读节奏不稳定：有时一口气读很久，有时又很久没有翻书。我想做一个不靠连续打卡施压、能帮我从上次页码继续的工具。

我做出的选择

先聚焦“推进—留痕—积累”：建立真实书架，再记录单次阅读，最后让真实记录逐渐形成可回看的轨迹。

现在做到哪一步

已有公开网页、邮箱登录基础，以及接入书籍数据的书架和页码更新代码。此次验收没有登录进行书籍新增或更新的真实写入复测。当前的轨迹页仍是说明性空状态。

下一步

完成开始、暂停与结束阅读，保存页数和文字感想，再用这些真实记录生成历史轨迹。

喵学园 · 项目详情与演示边界 ＋

校园里有同学自发照顾猫咪，却不容易知道别人已登记了哪些投喂，也很难持续看到同一只猫的故事。我希望先把“遇见猫咪—查看近期记录—补充记录与故事”做成可以体验的流程。

已经可以体验

浏览 8 只示例猫咪的名册、搜索和区域筛选，查看猫咪档案；创建投喂记录并在时间线查看；浏览成长日记、校园动态和个人页。桌面与手机布局均已做适配。

保存范围

自己添加的记录只保存在当前浏览器，刷新后仍可看到；其他访问者和设备看不到这些记录。“今日已记录的投喂”不代表猫咪当天的全部进食。

模拟演示

猫咪、用户、投喂和故事均为示例数据，账号为固定演示身份。“拍照识猫”通过颜色与亮度规则展示上传、候选和人工确认流程，并非真实 AI 识别。

尚未实现

多人共享、真实登录、云数据库、生产级图片存储和管理员权限隔离尚未完成；管理员页仅用于演示。

当前还需修复校园动态首次发布时的默认猫咪选择问题；示例“今日”时间会随长期使用变旧，图片存入浏览器也可能遇到容量限制。下一步是修复这些问题，再验证真实共享与校园试用。

Prompt Forest · 本地 MVP 与验证范围 ＋

好用的 Prompt 常散落在不同对话和网页里。我提出保存、分类、快速找回并复制复用的需求，和 AI 一起把它做成了可在本地运行的网页与 Chrome 插件演示版。

网页端已验证

可以新增 Prompt、选择或新建分类、按分类筛选、搜索和复制。记录与分类保存在当前浏览器，刷新后仍在；桌面与手机尺寸下的核心浏览操作可用。

划词收藏

在 Chrome 普通网页划词或使用右键菜单，可进入确认页保存，再到本机插件弹窗搜索、复制。这个闭环此前由我在 Chrome 实机确认；本轮验收核对了源码与自动测试，未重新加载插件实测。

演示边界

初始 8 条 Prompt 是内置演示数据；“最近整理”是简化标记，不是完整使用历史。网页和插件各自保存在本机浏览器中，没有账号或跨设备同步。

尚未完成

新版暂不支持编辑、删除 Prompt 或改名、删除分类；Edge、长期大量数据和不同网站的插入兼容性仍待验证。当前没有公开部署和可供访客使用的安装包。

HOW I GOT HERE

我一直在认真走路，
却很少认真选方向。

“女孩子做老师挺好的。”这是我很熟悉的一句话。高考填志愿时，我在自己的可选择范围里挑了一所遥远的学校，也选择了它很有优势的化学师范专业。那时的我并没有真正问过自己：我想成为什么样的人？

后来到了考研，我明明又拥有一次重新选择的机会，却还是下意识地把目光放在学科化学上。2025 年 3—6 月，我一边在中学实习，一边已经开始准备学科化学的研究生考试。

实习时，我很喜欢和学生们相处，也会和他们聊未来。听到一些孩子很清楚自己想要什么时，我反而开始羡慕他们。那时候我第一次认真问自己：我已经这么努力地沿着这条路往前走了，可它真的是我想一直走下去的方向吗？

我依然感谢教育学，也感谢一路遇到的老师和学生。正是这些经历让我开始意识到：女孩当然可以成为老师，也可以去做很多别的事情。过去的学习是我的来路，但不需要成为未来的边界。

现在，我想把研究生这两年当成一次真正的探索。去学习，去阅读，去寻找，也去创造一点属于自己的东西。也许现在的想法还不成熟，但我希望有一天，它们能真的长出枝枝蔓蔓。
